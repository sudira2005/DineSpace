# DineSpace

## Smart Restaurant Table Reservation System

### Group Project

DineSpace is a web application developed using React that allows customers to browse restaurants and reserve tables online.

## Features

- Home Page
- Restaurant Listing
- Restaurant Details
- Search Restaurants
- About
- Contact
- Login
- Register
- Customer Dashboard
- Admin Dashboard

## Technologies

- React
- Vite
- React Router
- CSS3
- JavaScript
